# 歷史複習工具

依課本與重點統整整理的單一 HTML 複習工具。涵蓋臺灣史（第一・二冊）與中國與東亞史（第三・四冊）。個人學習用。

線上版：<https://anitatsai13.github.io/taiwan-history-graph/>

## 分冊

| 冊 | 範圍 | 章 |
|---|---|---|
| **第一冊** | 史前～清帝國 | ① 史前與原住民　② 大航海時期　③ 清帝國時期 |
| **第二冊** | 日治～中華民國 | ④ 日治時期　⑤ 中華民國時期 |
| **第三冊** | 商周～晚清 | ⑤ 商周至隋唐　⑥ 宋元明清　⑦ 晚清變局 |
| **第四冊** | 民國～當代東亞 | ⑧ 民國建立與民初　⑨ 北伐抗日與國共　⑩ 中共與當代東亞 |

（前兩冊＝臺灣史，用課本自己的章號①～⑤；後兩冊＝中國與東亞史，用參考書的單元號 5～10。
兩者是不同科目、不同年代尺度，所以各一張關係圖。）

關係圖標頭有**冊籤**：按一下只看該冊，再按一次全部展開；章籤仍可單章開關。
`data.md` 也按同一套分冊編排（`# 跨冊總表` → `# 第一冊` → `# 第二冊` → `# 跨冊共用`）。

## 關係圖怎麼看

- **列**＝政權／年號／年代／事件／人物／地點／重點／主題，橫軸＝年代。
- **實線**＝主要關係，**虛線**＝對照，**箭頭 ➜**＝因果／前後關係
  （例：朝鮮問題 ➜ 甲午戰爭 ➜ 馬關條約 ➜ 臺灣民主國）。
- **★ 重點字**：點亮比較表裡標紅／藍的重點字，並在每顆節點下方垂一串「衛星掛點」。
- **▦ 比較表**：53 張表的統一入口；點節點也會帶出它掛的那張表。
- 搜尋支援多關鍵字（`長濱-台東`），Enter 逐筆跳轉。

### 衛星掛點可以自己改

★重點字模式下按右鍵：

- 右鍵**一顆衛星**：改文字／改顏色（紅＝核心、藍＝人名年代地區、灰＝地點補充）／上下移／插入／刪除
- 右鍵**節點**：編輯整串清單、新增、這節點不掛衛星、還原自動
- 右鍵**空白處**：匯出／匯入變更 JSON、全部還原

改的是疊在原始資料上的一層補丁，存在瀏覽器的 `localStorage["twhist_kw_v7"]`，
原始資料區不動、隨時可還原。換電腦或清瀏覽資料會消失，重要修改記得匯出 JSON。
細節見 `edit-plan.md`。

## 維護方式

工作檔在 `C:\Users\anita\Downloads\`，這個 repo 是**部署用的複本**。
改完工作檔後跑 `sync.ps1` 同步，再 commit push：

```powershell
powershell -ExecutionPolicy Bypass -File sync.ps1
git add -A
git commit -m "<改了什麼>"
git push origin main
```

（`sync.ps1` 存成 **UTF-8 with BOM**——Windows PowerShell 5.1 沒有 BOM 會把中文檔名讀成亂碼，
於是每個檔都「找不到」。另外這台機器的執行原則預設不跑腳本，所以要加 `-ExecutionPolicy Bypass`。）

GitHub Pages 從 `main` 部署，push 完約 1 分鐘生效。
